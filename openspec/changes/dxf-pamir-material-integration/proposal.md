## Why

Currently, the DXF files generated by the backend are flat 2.5D wireframes where truss elevation profiles are drawn directly on the 2D layout plane. This visualization is useful for simple previews, but it does not represent the actual 3D structure of the roof or walls. Consequently, designers importing these files into professional framing software like MiTek Pamir must manually scale, calculate centerlines, and re-create 3D coordinates.

Transitioning the DXF output to a true 3D wireframe layout with clean layer separation, dedicated wall centerlines, and isolated technical annotations will make the design snappable and directly usable inside Pamir, drastically reducing the manual tracing workload.

## What Changes

- **True 3D Wireframe Geometry**: Upgrade the DXF generator to output 3D lines (`(x, y, z)` coordinates) representing the actual spatial layout of the building walls (with thickness/height), the roof boundary (at eave and ridge heights), and the individual truss placements in 3D space.
- **Dedicated Wall Centerlines Layer**: Introduce a new layer (`Wall_Centerlines`) containing single centerline vectors for all structural walls, enabling rapid snap-tracing in Pamir.
- **Layer Cleanliness and Isolation**: Keep all dimensions, user-facing labels, and technical annotations on separate layers:
  - `Dimensions`: Visible lines and measurements.
  - `Labels`: Readable user-facing labels (e.g. building name, location, width/depth).
  - `Lumber_Specs` (New): Technical annotations detailing wood grade (e.g., C24) and material specs, visible to Pamir designers but hidable for end-user previews.
- **Standardized Millimeter Scale**: Maintain a strict 1:1 scale where 1 unit in DXF = 1 millimeter, eliminating the scaling step in Pamir.

## Capabilities

### Modified Capabilities

- `dxf-builder`: Update the DXF builder specification to generate 3D wireframe entities (3D walls, 3D roof boundaries, 3D truss outlines), support a dedicated `Wall_Centerlines` layer, a `Lumber_Specs` layer, and maintain strict layer separation for dimensions/labels.
- `dxf-truss-layout`: Update truss drawing requirements from 2.5D projected cross-sections to true 3D wireframe triangle shapes placed at their actual spatial spacing along the Z-axis (elevation offset).
- `dxf-dimensions-annotations`: Update dimension layout and add the new `Lumber_Specs` layer containing technical material descriptions (wood grade, thickness, width) separate from user-facing annotations.

## Impact

- **Backend (`agent/src/dxf_builder.py`)**: Major update to the geometry generator functions (`_draw_floor_plan`, `_draw_trusses`, and roof shapes) to construct 3D coordinates rather than 2D/2.5D.
- **Backend API (`agent/src/main.py`)**: No signature changes, but the output bytes returned by `/api/dxf/generate` will contain the new 3D DXF structure.
- **Frontend CAD Viewer**: The React viewer component will render the new 3D wireframe geometry. (Note: standard three-dimensional rotating/pan functions in the viewer will render 3D coordinates correctly).
