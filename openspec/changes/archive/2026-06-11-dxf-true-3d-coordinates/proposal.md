## Why

The current generated DXF files use a 2D isometric projection matrix (`_to_iso`) on the backend to flatten 3D coordinates into a 2D drawing. When loaded into the newly integrated 3D CAD orbit viewer (`CadViewer3D`), the drawing renders as a flat 2D sheet of paper floating in 3D space rather than a true 3D spatial wireframe model. Using real 3D coordinates (with actual Z values) directly in the DXF file allows the 3D viewer to render a true 3D model that users can orbit and inspect from any angle.

## Scope

- **In-Scope**: Modifying backend coordinate calculations in `agent/src/dxf_builder.py` and test assertions in `test/test_dxf_builder.py` to support and verify true 3D coordinates.
- **Out-of-Scope/Non-Goals**:
  - Modifying frontend TSX viewer components or layout structures.
  - Customizing `@mlightcad/cad-simple-viewer` (the 2D viewer) to compute or draw custom isometric projections on the client side.
  - Altering the LLM agent's prompts, layer names, or text labels.

## What Changes

- **BREAKING**: Modify DXF coordinate generation in `dxf_builder.py` to use true 3D coordinates $(X, Y, Z)$ rather than flattening/projecting them using `_to_iso` to the 2D isometric plane.
- Remove the `_to_iso` helper function from `dxf_builder.py` as it is no longer required.
- Place all floor plan wall box, roof framing, and truss lines at their actual, physical 3D locations in space (e.g. wall height $Z = 2700$, ridge height $Z = 2700 + \text{ridge\_h}$).
- Insert dimension labels (TEXT/MTEXT) at 3D coordinate insertion points (typically on the ground plane $Z=0$ or at height $Z$ without isometric projection).
- Update the backend test suite in `test_dxf_builder.py` to assert correct 3D coordinates rather than 2D projected coordinates.

## Capabilities

### New Capabilities

*(None)*

### Modified Capabilities

- `dxf-builder`: Modify the floor plan and roof framing coordinates to be real 3D (X, Y, Z) coordinates instead of 2D projected isometric coordinates.
- `dxf-truss-layout`: Modify truss lines to be drawn at their true 3D coordinates (spaced along the Depth axis at their physical X or Y locations, with height Z).
- `dxf-dimensions-annotations`: Position text and annotations at actual 3D coordinates (e.g., ground plane $Z=0$) rather than 2D projected isometric coordinates.

## Impact

- **Backend**: `agent/src/dxf_builder.py` and `test/test_dxf_builder.py` will be modified.
- **Frontend**: The 3D viewer (`src/components/cad-viewer-3d.tsx`) will now display a true 3D model. The 2D viewer (`src/components/cad-viewer.tsx`) will display the model in its default top-down orthographic plan view (looking down the Z-axis, showing X and Y coordinates), which is standard behavior for 2D CAD layouts.

## Rollout Boundaries

- This change applies globally to all DXF outputs generated by the `build_dxf` API endpoint. 
- The generated DXFs will immediately serve the true 3D coordinate payload to both the 2D plan viewer and the 3D orbit viewer without requiring updates to their parsing or rendering integration code.
