## ADDED Requirements

### Requirement: Timber members have material associations
The system SHALL associate material data with timber members generated by the IFC builder using standard IFC relationships.

#### Scenario: Verify timber material association
- **WHEN** the IFC file is generated for a design containing timber members
- **THEN** it SHALL define an IfcMaterial entity with name "Timber - C24"
- **AND** it SHALL link the material definition to all generated IfcMember entities using IfcRelAssociatesMaterial.
