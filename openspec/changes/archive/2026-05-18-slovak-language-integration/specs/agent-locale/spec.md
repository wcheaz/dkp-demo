## ADDED Requirements

### Requirement: Agent system prompt adapts to locale
The Python agent's system prompt SHALL be generated by a function `get_system_prompt(locale: str) -> str` that appends a locale-specific language instruction. When `locale` is `"sk"`, the prompt SHALL end with an instruction to respond in Slovak. When `locale` is `"en"`, the prompt SHALL end with an instruction to respond in English. When `locale` is any other value, the default SHALL be Slovak.

#### Scenario: Slovak locale instruction appended
- **WHEN** `get_system_prompt("sk")` is called
- **THEN** the returned string SHALL contain the substring "Respond in Slovak"

#### Scenario: English locale instruction appended
- **WHEN** `get_system_prompt("en")` is called
- **THEN** the returned string SHALL contain the substring "Respond in English"

#### Scenario: Unknown locale defaults to Slovak
- **WHEN** `get_system_prompt("de")` is called
- **THEN** the returned string SHALL contain the substring "Respond in Slovak"

#### Scenario: Base prompt content is preserved
- **WHEN** `get_system_prompt("en")` is called
- **THEN** the returned string SHALL still contain all existing content (tool catalog, ABSOLUTE RULES, etc.)

### Requirement: Frontend passes locale to agent via CopilotKit context
The frontend SHALL forward the current locale value to the backend agent through CopilotKit's context mechanism. The agent SHALL read the locale from the CopilotKit-provided context or state deps and use it when generating the system prompt.

#### Scenario: Locale is available in agent context
- **WHEN** the frontend has `locale` set to `"sk"` and sends a message to the agent
- **THEN** the agent SHALL receive `"sk"` as the locale value in its context/state deps

#### Scenario: Locale defaults to Slovak when not provided
- **WHEN** the agent receives no locale value in its context
- **THEN** the agent SHALL default to `"sk"` for the system prompt language instruction
