## MODIFIED Requirements

### Requirement: System prompt enforces ASCII-only output
The system prompt SHALL instruct the agent to NEVER use emojis, Unicode symbols, or pictographs. All output MUST be plain ASCII. This requirement is UNCHANGED — the ASCII-only rule applies regardless of the agent's response language.

#### Scenario: Emoji prohibition in prompt
- **WHEN** the system prompt is read (for any locale)
- **THEN** it SHALL contain the phrase "NEVER include emojis" and list forbidden example emojis

### Requirement: System prompt is locale-aware
The system prompt SHALL be generated by a function `get_system_prompt(locale: str) -> str` instead of being a static string. The function SHALL append a locale-specific language instruction at the end of the base prompt. The base prompt content (tool catalog, ABSOLUTE RULES, output style, collection loop) SHALL remain unchanged.

#### Scenario: Slovak language instruction appended
- **WHEN** `get_system_prompt("sk")` is called
- **THEN** the returned prompt SHALL end with a language instruction containing "Slovak" or "Slovenčina"

#### Scenario: English language instruction appended
- **WHEN** `get_system_prompt("en")` is called
- **THEN** the returned prompt SHALL end with a language instruction containing "English"

#### Scenario: Default locale is Slovak
- **WHEN** `get_system_prompt()` is called with no argument
- **THEN** the returned prompt SHALL contain the Slovak language instruction

#### Scenario: Base prompt rules are preserved for all locales
- **WHEN** `get_system_prompt("en")` or `get_system_prompt("sk")` is called
- **THEN** the returned prompt SHALL still contain "ABSOLUTE RULES", "Tool catalog", and all existing tool usage instructions unchanged
